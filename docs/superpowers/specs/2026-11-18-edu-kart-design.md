# 공부 카트 레이스 설계 (짧은 버전)

## 의도
- 초등학생이 레이싱을 하면서 산수·영어를 연습한다.
- 어른이 해도 레이싱 자체가 재미있어야 한다. 공부가 재미를 깎으면 실패.

## 방식 (선택: A)
- **A. 정답 차선 통과 (선택)**: 트랙의 문(3개 차선)에 보기가 붙고, 맞는 문을 지나면 부스터, 틀리면 감속. 멈추지 않고 운전이 곧 풀이.
- B. 아이템 박스 = 문제: 공부 효과 약하고 운전 중 읽기 산만.
- C. 랩 사이 퀴즈: 흐름이 끊겨 어른에게 지루.

## 결정 사항
- 웹 브라우저 게임, Three.js 3D, 설치 없음 (index.html 더블클릭).
- 혼자 + 컴퓨터 상대 4대. 한 화면 2인은 다음 단계.
- 과목: 산수(덧뺄셈 / 구구단·두 자리 / 나눗셈·세 자리), 영어(그림→단어 / 단어→뜻 / 뜻→단어).
- 수준: 1~2학년, 3~4학년, 5~6학년.
- 영어 단어는 브라우저 음성(speechSynthesis)으로 읽어줌.
- 틀린 문제는 브라우저(localStorage)에 저장, 다음 경주에서 30% 확률로 다시 출제.
- 재미 요소: 드리프트 게이지 → 부스터, 정답 콤보로 부스터 강화, 아이템 박스(부스터·바나나), 컴퓨터도 바나나를 떨어뜨림.
- 트랙 2개(초원 서킷, 사막 협곡), 3바퀴, 한 바퀴에 문 5개.
- 결과 화면: 순위, 기록, 정답률, 틀린 문제와 정답.

## 하지 않을 것
- 온라인 대전, 로그인, 결제, 광고.
- 카트라이더의 이름·캐릭터·트랙 사용. 그림과 이름은 모두 새로 만든다.

## 구현자 재량 (내가 정한 것)
- 조작: 방향키/WASD, Shift 드리프트, Space 아이템. 터치 기기는 자동 가속 + 화면 버튼.
- 컴퓨터 상대는 트랙 중심선을 따라 움직이고, 문에서 70% 확률로 정답 처리. 격차가 크면 속도를 조금 조절(고무줄 효과).

## 2차 수정 (사용자 피드백 반영)
피드백: 배경·카트·캐릭터가 너무 단순함, 카트 움직임이 너무 가벼움, 보기는 눈에 띄는데 문제는 안 보임.
- 그래픽: 카툰(toon) 재질 + 외곽선, 그림자, 하늘 그라데이션, 먼 산/메사, 구름, 나무·덤불·꽃·연못·선인장·모래언덕, 관중석, 트랙 깃발, 아스팔트 질감.
- 카트: 둥근 차체, 스포일러, 배기구 불꽃, 조향되는 앞바퀴, 회전하는 바퀴, 핸들.
- 캐릭터: 직접 만든 동물 5종(곰, 고양이, 토끼, 개구리, 펭귄), 고글·목도리, 메뉴에서 선택. 기존 게임 캐릭터는 쓰지 않음.
- 주행감: 속도·방향 분리(옆미끄러짐), 서서히 꺾이는 핸들, 무거운 가속 곡선, 차체 기울기/들림, 벽에 튕김과 화면 흔들림, 늦게 따라오는 카메라, 속도선, 엔진 소리.
- 드리프트: 깡충 → 미끄러지며 충전 → 떼면 미니 부스터(파랑/주황). 스타트 대시 추가.
- 문제 표시: 크림색 큰 카드에 문제를 가장 크게(최대 86px), 보기는 아래 작게, 새 문제마다 튀어나오는 효과, 문까지 거리 막대, 3D 문 위에도 문제판.
- 기타: 미니맵, 아이템 룰렛, 효과음(WebAudio 합성, 파일 없음).

## 3차 수정 (사용자 피드백 반영)
피드백: 키 반응은 느린데 휙휙 돌아서 조종이 어려움, 도로가 좁고 너무 빨라 다음 문제가 순식간, 트랙이 짧고 단순히 빙글빙글 돌기만 함.
- 조향: 키 입력은 0.1초 안에 반응, 최대 회전은 낮춤(최고 속도에서 반경 약 38). 카메라도 차 방향을 빠르게 따라가 화면이 휘청이지 않게 함.
- 속도: 최고 속도 52 → 38 (화면 표시는 약 120km/h), 가속도 완만하게.
- 도로 폭 24 → 40 (+ 양쪽 갓길 5, 갓길은 느려짐), 차선 간격 8 → 12.
- 트랙 길이 약 2.7배 (초원 2674, 사막 3171), 2바퀴, 한 바퀴에 문 5~6개 → 문 사이 약 10~16초.
- 초원 서킷: 8자 코스 + 교차 다리(아래로 다른 길이 지나감), 언덕, 점프대 2개, 꽃 아치 터널, 개울 건너기(물보라, 살짝 느려짐), 길을 가로지르는 양떼, 부스터 발판, 풍차, 열기구.
- 사막 협곡: 메사 위로 올라가는 오르막, 절벽 점프(점프대 + 낭떠러지), 바위 아치 협곡, 굴러오는 바위, 부스터 발판, 점프대.
- 높이 물리: 중력 + 도로 따라가기, 언덕 꼭대기·점프대 끝에서 실제로 뜸, 오르막 감속/내리막 가속, 공중 트릭 → 착지 부스터.

## 4차 수정: 상용 품질 다듬기 (사용자 요청: 약 1시간, HTML 외 기술도 허용)
- 기술은 웹(Three.js) 유지: 이미 동작하는 결과물을 버리지 않고, 설치 없이 바로 실행되는 장점을 지킴. 대신 ES 모듈로 후처리(EffectComposer) 도입.
- 소리: 효과음/음악 버스 분리 + 컴프레서, 배경음악 시퀀서(곡 3개 + 징글), 음량 설정.
- 화면: 빛 번짐·색 보정·비네트·속도 블러·FXAA, 그래픽 품질 설정과 자동 낮춤.
- 흐름: 로딩 → 출발 전 카메라 비행(건너뛰기 가능) → 신호등 → 경주 → 골인 카메라 → 시상대 결과(순위표, 별점, 최고 기록) / 일시정지·설정 메뉴.
- 게임성: 난이도 3단계, 컴퓨터 아이템 사용, 마지막 바퀴 알림과 음악 가속, 역주행 경고, 첫 경기 안내.

## 5차 수정: 트랙 구조와 배경 (사용자 피드백: 트랙이 단순하고 커브 반경이 비슷함, 배경 품질 낮음, 휴대폰 검토는 불필요)
- 트랙: 수식 곡선 대신 직선/원호 조각을 이어 붙이는 방식(`js/trackgen.js`). 끝은 Dubins 경로로 출발점에 정확히 닫힘.
  - 초원(2713): 8자 + 다리 교차(100도). 반경 40~200 커브, S자, 긴 직선, 헤어핀 2곳.
  - 사막(2401): 긴 직선, 빠른 꺾임(반경 220), 메사 오르막, 절벽 점프(높이 13), S자, 헤어핀(반경 30), 협곡.
  - 설계 도구로 도로끼리 겹침 0곳 확인, 문·점프대·부스터는 모두 직선 위(반경 측정).
- 배경: 높이맵 지형(트랙 근처 평평 → 언덕 → 가장자리 산맥, 초원은 눈 덮인 봉우리, 사막은 층층 메사), 숲 덩어리 배치, 풀숲·꽃 수천 개, 반짝이는 호수, 해, 구름 30개, 광고판, 급커브 바깥 타이어 벽, 사막 협곡 암벽.
- 휴대폰 검토는 하지 않음 (실행 환경 아님).
