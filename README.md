# 공부 카트 레이스

초등학생용 3D 카트 레이싱 + 산수/영어 학습 게임. 설계: `docs/superpowers/specs/2026-11-18-edu-kart-design.md`

## 실행
- `index.html`을 크롬/엣지로 열면 된다. 설치 없음.
- Three.js(0.149, 후처리 모듈 포함)와 글꼴 Jua를 인터넷에서 받으므로 인터넷이 필요하다. 못 받으면 안내 화면이 뜬다.

## 조작
- 방향키 또는 WASD: 운전
- Shift 를 누른 채 방향키: 드리프트 (깡충 → 미끄러지며 충전 → 떼면 파랑/주황 부스터)
- 점프대·언덕에서 공중에 떴을 때 Shift: 트릭 → 착지하면 부스터
- Space: 아이템 (🚀 부스터, 🍌 바나나)
- Esc 또는 P: 일시정지 / M: 소리 켜기·끄기
- 출발 신호 마지막 1초 안에 가속을 누르기 시작하면 스타트 대시
- 터치 기기: 자동 가속 + 화면 버튼

## 들어있는 것
- 트랙 2개: 초원 서킷(8자 다리, 꽃 터널, 개울, 양떼, 풍차), 사막 협곡(메사 오르막, 절벽 점프, 바위 아치, 굴러오는 바위)
- 캐릭터 5종, 컴퓨터 상대 4명(아이템 사용), 난이도 3단계
- 배경음악(메뉴/초원/사막, 마지막 바퀴에 빨라짐)과 효과음: 모두 WebAudio 로 합성, 음원 파일 없음
- 후처리: 빛 번짐, 색 보정, 비네트, 부스터 때 가장자리 속도 블러, FXAA. 그래픽 '빠르게'를 고르면 끔
- 연출: 출발 전 카메라 비행, 신호등, 마지막 바퀴 배너, 순위 변화 효과, 역주행 경고, 골인 카메라, 시상대 결과 화면, 별점, 최고 기록
- 첫 경기 안내, 로딩 화면, 계속 느리면 그래픽 자동 낮춤
- 저장(브라우저): 설정, 트랙별 최고 기록, 틀린 문제(다음에 다시 출제)

## 파일
- `js/questions.js` 문제 생성 (산수/영어, 틀린 문제 다시 내기)
- `js/models.js` 카툰 3D 모델 (카트, 동물 캐릭터, 양, 풍차, 열기구, 점프대, 나무 등)
- `js/music.js` 배경음악 시퀀서
- `js/game.js` 트랙, 주행 물리, 컴퓨터 상대, 화면(HUD), 소리, 메뉴, 후처리

## 점검
- 문제 생성기 테스트: `node test/questions.test.js`
- 자율주행 점검: `index.html#sim=400` (선택: `&track=1&subject=english&species=cat&drift=1`)
  → 레이스를 빠르게 끝까지 돌리고 콘솔에 `SIM {...}` 결과(순위, 정답, 벽 충돌, 평균 속도 등) 출력
- `#race=초` 는 그 시간까지 진행한 뒤 화면을 유지한다 (스크린샷용, `&pause=1` 이면 일시정지 화면). `#intro` 는 출발 전 연출 화면.

## 실제 브라우저 점검 결과 (2026-11-18)
- 인터넷 차단 상태에서 실행: 외부 요청 0건, 3D 라이브러리·글꼴 모두 로컬에서 로드
- 크롬과 엣지(157)에서 메뉴 → 설정 → 출발 → 출발 연출 건너뛰기 → 주행 → 드리프트 → 일시정지/계속: 콘솔 오류 0건
- 벽에 막혀도 저속 회전 + 2.5초 뒤 자동 구조로 다시 달림
- 음악 3곡 오프라인 녹음: 소리 남(RMS 0.09~0.12), 최대 0.58~0.75로 찢어짐 없음. 들어보기: `docs/audio-preview/*.wav`
- RTX 4060 Ti(크롬, D3D11): 두 트랙 모두 144fps(화면 주사율 한계), 한 프레임 계산 약 2ms
- 최악 조건 흉내(그래픽카드 없이 소프트웨어 렌더링 + CPU 4배 느리게): 그래픽 자동 낮춤 동작, '빠르게' 모드 16~19fps
- 휴대폰 크기(390×844, 터치) 메뉴·주행 화면 확인
