# 공부 카트 레이스

초등학생용 3D 카트 레이싱 + 산수/영어 학습 게임.
설계: `docs/superpowers/specs/2026-11-18-edu-kart-design.md`, 6차 확장: `docs/superpowers/specs/2026-11-23-edu-kart-expansion-design.md`

## 실행
- `index.html`을 크롬/엣지로 열면 된다. 설치 없음.
- Three.js(0.149, 후처리 모듈 포함)와 글꼴 Jua는 `vendor/` 폴더에서 읽으므로 인터넷 없이 실행된다. `vendor/`가 없으면 안내 화면이 뜬다.

## 조작
- 방향키 또는 WASD: 운전
- Shift 를 누른 채 방향키: 드리프트 (깡충 → 미끄러지며 충전 → 떼면 파랑/주황 부스터)
- 점프대·언덕에서 공중에 떴을 때 Shift: 트릭 → 착지하면 부스터
- Space: 아이템 사용 (첫 칸), ↓(S) 누른 채 Space: 물풍선·얼음 벽을 뒤로
- Esc 또는 P: 일시정지 / M: 소리 켜기·끄기
- 출발 신호 마지막 1초 안에 가속을 누르기 시작하면 스타트 대시
- 터치 기기: 자동 가속 + 화면 버튼

## 들어있는 것
- 트랙 4개 (모두 지름길 1곳)
  - 초원 서킷: 8자 다리, 꽃 터널, 개울, 양떼, 풍차, 진흙 지름길(입구가 급해서 감속·드리프트 필요)
  - 사막 협곡: 메사 오르막, 절벽 점프, 바위 아치, 굴러오는 바위, 모래 지름길(출발선을 가로지름)
  - 눈 산길: 헤어핀, S자, 언덕 2곳, 얼음 구간, 눈 터널, 굴러오는 눈덩이, 얼어붙은 호수를 건너는 얼음 지름길
  - 해안 도로: 바닷가 긴 직선(파라솔·등대·갈매기·게), 물웅덩이, 절벽 위 다리, 모래사장 지름길
- 길: 급한 커브일수록 바깥쪽이 높아짐(최대 약 8도). 노면은 얼음(미끄러움), 모래·진흙(느림)
- 캐릭터 8종 (곰, 고양이, 토끼, 개구리, 펭귄, 여우, 판다, 오리), 컴퓨터 상대 7명
- 컴퓨터 성격 3가지: 공격형(커브 안쪽, 멀리서 공격), 안정형(정답률 높음, 위험할 때만 방패), 장난꾸러기(함정을 자주 깜). 난이도 3단계
- 경주 3바퀴, 난이도 3단계 (컴퓨터 속도 배율 쉬움 0.97 / 보통 1.07 / 어려움 1.13)
- 아이템 14종, **2칸**까지 들 수 있음 (Space 로 첫 칸 사용, 뒤 칸이 당겨짐)
  - 아이템 줄마다 금색 상자 1개: 아이템 2개
  - 순위별 확률 5묶음: 1등(바나나·방패·꿀 위주) / 2~3등 / 중간 / 뒤 / 꼴찌. 첫 바퀴 동안 1등은 2~3등 표, 정답 콤보 3 이상이면 한 묶음 좋은 표
  - 뒤에서 공격이 날아오면 아이템 칸 위에 경고(⚠️ + 거리 막대), 첫 칸이 방패면 "Space 로 🛡️!"

  | 아이템 | 효과 |
  |------|------|
  | 🚀 부스터 | 2초 가속 |
  | 🍌 바나나 | 뒤에 놓음, 밟으면 미끄러져 돎 |
  | 🚀 부스터 3개 | 부스터를 세 번 나눠 씀 |
  | 🛡️ 방패 | 8초 동안 공격·함정 1회를 막음 |
  | 🎈 물풍선 | 앞으로 던짐(벽에 튕김), ↓ 누른 채 Space 면 뒤로 |
  | 🎯 따라가는 물풍선 | 바로 앞 순위 카트를 따라가 맞힘 |
  | 🍯 꿀 웅덩이 | 뒤에 깔림, 밟으면 3초 크게 느려짐 |
  | 🧊 얼음 벽 | 앞으로 약 50 던져 놓음, ↓ 누른 채 Space 면 바로 뒤. 부딪히면 튕김, 10초 뒤 녹음 |
  | 🫧 비눗방울 구름 | 앞 순위 모두 3초 동안 핸들이 둔해짐 (화면 가장자리만 가림) |
  | 🌈 무지개 별 | 6초 무적 + 가속, 부딪힌 카트는 돎 |
  | 💡 힌트 전구 | 다음 문에서 오답 하나를 지움 |
  | 🐝 벌떼 | 상공으로 길을 따라 날아가다 1등 근처(60)에서 내리꽂아 1등과 주변(반경 10) 카트를 모두 쏨. 시간 제한 없음, 출동하면 모두에게 알림. 중간 순위부터 나옴, 내가 1등이면 들고 있음 |
  | 🌀 회오리 | 앞으로 천천히 굴러가며 지나는 카트를 모두 돌림 |
  | 🪃 부메랑 | 앞으로 갔다가 돌아옴, 가는 길·오는 길 각 한 대를 맞힘 |
- 문제 유형
  - 산수 1~2학년: 덧셈·뺄셈, 빈칸 채우기(□ + 3 = 7), 크기 비교(○ 에 >, <, =), 개수 세기
  - 산수 3~4학년: 구구단, 두 자리 덧뺄셈, 빈칸 곱셈, 시계 읽기, 길이 단위(m, cm, mm)
  - 산수 5~6학년: 곱셈·나눗셈·세 자리, 분수 크기 비교, 분수 덧셈, 소수 계산, 혼합 계산(곱셈 먼저)
  - 영어(단어 135개): 그림 → 단어, 듣고 그림 고르기, 첫 글자, 단어 → 뜻, 빠진 모음, 뜻 → 단어, 맞는 철자 고르기, 반대말
- 배경음악(메뉴 + 트랙마다 1곡, 마지막 바퀴에 빨라짐)과 효과음: 모두 WebAudio 로 합성, 음원 파일 없음
- 후처리: 빛 번짐, 색 보정, 비네트, 부스터 때 가장자리 속도 블러, FXAA. 그래픽 '빠르게'를 고르면 끄고 컴퓨터 카트 외곽선도 숨김
- 연출: 출발 전 카메라 비행, 신호등, 마지막 바퀴 배너, 순위 변화 효과, 역주행 경고, 골인 카메라, 시상대 결과 화면, 별점, 최고 기록
- 첫 경기 안내, 로딩 화면, 계속 느리면 그래픽 자동 낮춤
- 저장(브라우저): 설정, 트랙별 최고 기록, 틀린 문제(다음에 다시 출제)

## 파일
게임 스크립트는 일반 `<script>` 파일들이 최상위 선언을 서로 공유하는 방식이다 (더블클릭 실행을 위해 ES modules 를 쓰지 않음). `index.html` 의 순서대로 읽힌다.

| 파일 | 내용 |
|------|------|
| `js/questions.js` | 문제 생성 (유형 표 `TYPES`, 틀린 문제 다시 내기). node 에서도 읽힘 |
| `js/itemtable.js` | 아이템 14종과 순위별 확률표(5묶음). node 에서도 읽힘 |
| `js/trackgen.js` | 트랙 모양(직선·원호 조각), 지름길 경로, 커브 기울기, 노면. node 에서도 읽힘 |

| `js/audio.js` | 효과음 |

## 점검
- node 테스트: `node test/questions.test.js`, `node test/items.test.js`, `node test/items-hit.test.js`(방패·별·물풍선 맞음 처리), `node test/tracks.test.js`, `node test/trackgen.test.js`, `node test/globals.test.js`
  - `tracks.test.js`: 닫힌 고리, 도로끼리 겹침, 점프대·발판·문 위치, 지름길 조건(충분히 짧음, 본 도로와 떨어짐, 출구 뒤 문까지 100 이상)
  - `globals.test.js`: 파일끼리 이름 겹침(function 포함), 파일 600줄 이하
- 자율주행 점검: `node test/sim.mjs` (headless 크롬으로 `index.html#sim=600` 기본 4가지를 돌려 결과 출력, 콘솔 오류가 있으면 실패)
  - 해시 인자는 순서 상관없음: `track`, `subject`, `level`, `difficulty`, `species`, `seed`(같은 시드 = 같은 결과), `drift=1`, `shortcut=1`(지름길로 달림)
  - 컴퓨터가 한 프레임에 3 넘게 튀면(`aiJump`) 실패. `--save 파일` / `--compare 파일`: 결과 저장·비교, `--swiftshader`: 그래픽카드 없이 소프트웨어 렌더링
  - 예: `node test/sim.mjs "sim=600&track=3&shortcut=1"`, 성능: `node test/sim.mjs --swiftshader "bench&track=2&quality=low"`, 음악: `node test/sim.mjs audiotest`
- 스크린샷: `node test/shot.mjs 출력.png "race=30&track=2"`
  - `race=초`: 그 시간까지 진행한 뒤 화면 유지 (`&pause=1` 일시정지, `&use=아이템` 그 아이템 사용)
  - `intro[&track=n]`: 출발 전 연출 화면, `showcase=종[&ang=각도]`: 메뉴 캐릭터 화면

## 점검 결과 (2026-11-24, 7차 ① 아이템·난이도)
- node 테스트 6개 모두 통과 (확률표 5묶음, 2칸, 던지는 방향, 새 아이템 맞히는 규칙, 경고 판단)
- 자율주행(정답 100%) 보통 난이도 4트랙 18경주: 모두 3바퀴 완주, 17/18 이 3등 안, 다른 카트 공격에 맞은 횟수 평균 1.6회 (자율주행은 멀리 앞서 나가서 실제 플레이보다 적게 맞음 — 실제 플레이로 확인 예정)
- 쉬움 1등·1등, 어려움 2등·3등 (시드 2개씩)
- 컴퓨터가 모든 아이템을 사용 (여러 시드 합)

## 점검 결과 (2026-11-23, 6차 확장)
- node 테스트 6개 모두 통과
- 자율주행(정답 100%) 4트랙 × 산수·영어: 모두 2바퀴 완주, 콘솔 오류 0. 보통 난이도 1등, 어려움 2등. 한 경주에 아이템에 맞는 횟수 0~3
- 지름길 주행(`shortcut=1`): 4트랙 모두 두 바퀴 모두 지름길 진입, 바퀴 수 정상
- 아이템 12종: 여러 시드에서 컴퓨터가 12종 모두 사용, 방패 막기 동작
- 게임을 파일로 나눈 뒤 같은 시드의 sim 결과가 나누기 전과 완전히 같음
- 음악 5곡 오프라인 녹음: 최대 0.55~0.85, RMS 0.087~0.121, 찢어짐 없음
- 소프트웨어 렌더링(headless SwiftShader, 1280×720, '빠르게'): 4트랙 13~15fps. 같은 환경에서 확장 전(컴퓨터 4대, 트랙 2개)도 13fps

## 이전 점검 결과 (2026-11-18)
- 인터넷 차단 상태에서 실행: 외부 요청 0건, 3D 라이브러리·글꼴 모두 로컬에서 로드
- 크롬과 엣지(157)에서 메뉴 → 설정 → 출발 → 출발 연출 건너뛰기 → 주행 → 드리프트 → 일시정지/계속: 콘솔 오류 0건
- RTX 4060 Ti(크롬, D3D11): 두 트랙 모두 144fps(화면 주사율 한계), 한 프레임 계산 약 2ms
- 최악 조건 흉내(그래픽카드 없이 소프트웨어 렌더링 + CPU 4배 느리게): 그래픽 자동 낮춤 동작, '빠르게' 모드 16~19fps

## 사람이 직접 확인할 것 (자동으로는 확인 불가)
- 아이가 직접 해 보며: 핸들 감각, 문제를 읽을 시간이 충분한지, 컴퓨터 상대 난이도, 아이템이 너무 세거나 약하지 않은지
- 초원 진흙 지름길 입구가 아이에게 너무 어렵지 않은지
- 새 문제 유형(시계, 분수, 철자 등)의 글자가 읽기 쉬운지, 영어 듣기 문제의 음성
- 배경음악·효과음이 듣기 좋은지, 음량 균형
- 실제 저사양 기기에서 컴퓨터 8대 + 새 트랙 속도
